# LuckyWheel v2.0.8 — Windows x64

C++17 / Qt Widgets 幸運轉盤，支援獎品庫存、歷史紀錄、CSV/JSON 與九語介面。
本次僅修正公開前授權通知與封裝，版本維持 2.0.8。

**發布狀態：Repo 與本機完整 Release 套件 GO，尚未推送 GitHub。**
見 [RELEASE-STATUS.md](RELEASE-STATUS.md) 的持續義務與驗證範圍。此目錄沒有已建立的 GitHub Release。

## 取得與執行

- 安裝版：`LuckyWheel-2.0.8-Windows-x64-Setup.exe`。
- 免安裝版：完整解壓 `LuckyWheel-2.0.8-Windows-x64-Portable.zip`，開啟根目錄的 `LuckyWheel.exe`。
- 原始碼：`LuckyWheel-2.0.8-source.zip`，不含 runtime、build、packages、歷史驗證紀錄或舊網頁版。
- 原始碼需自行建置：執行 `build.cmd`，完成後開啟 `build/dist/LuckyWheel.exe`；詳見 [BUILD.md](BUILD.md)。

完整發布套件位於 packages/prepublish-20261030；兩項授權／來源交付修正已完成。程式與安裝包尚未簽章。
安裝版和免安裝版均需保留 DLL、外掛、licenses 與發布狀態文件；不必另行安裝 Qt。

資料預設位於 `%LOCALAPPDATA%/LuckyWheel/LuckyWheel/`，程式離線工作。
如需隔離資料，可執行 `LuckyWheel.exe --data-dir "D:\LuckyWheelData"`。
安裝、升級、備份與解除安裝說明見 [INSTALL.md](INSTALL.md)。

## 功能

- 每個獎品設定名稱、機率、總數、剩餘數量與顏色。
- 機率支援四位小數百分比，最低單位為 `0.0001%`。只接受一般十進位、小數點使用 `.`，不接受科學記號或自動四捨五入。
- 機率總和不可超過 100%；不足部分自動成為「未中獎」。
- 總數、剩餘數量都是整數；`-1 / -1` 代表不限量。剩餘數量不可超過總數。最多 200 個獎品，名稱最多 120 字元。
- 售罄獎品機率轉成未中獎，其他獎品的機率保持不變。
- 可顯示或隱藏售罄區塊；灰色售罄區塊代表未中獎，不代表還能取得該獎品。隱藏後整個面積合併到未中獎。
- 配置、庫存、歷史與介面設定自動儲存於 SQLite。
- 保存／重載配置、匯出／載入 JSON、重置数量並建立新一輪；歷史保留。
- 歷史依時間與流水號由新到舊排列。顯示本機時間，CSV 使用 UTC 時間。紀錄保存抽獎當時的有效機率與隨機值。
- 中獎與未中獎音效、音量／靜音，中獎彩紙效果。
- 九語：繁中、簡中、英、日、韓、西班牙、法、德、葡萄牙。
- CSV 批次匯入與確認前預覽、歷史 CSV 匯出、JSON 配置檔。
- 一致性資料庫備份、還原前自動安全備份、明亮／深色外觀。
- 全螢幕按 F11，Esc 離開全螢幕。檔案或確認對話框開啟時，Esc 會先取消該對話框。
- 歷史統計；獨立機率模擬最多 100 萬次，不扣正式庫存、不寫正式紀錄。
- 設定密碼鎖定；鎖定時仍可抽獎、查看與匯出紀錄、備份及模擬。

首次啟動有範例 A（10%、3份）與 B（20%、5份），剩餘 70% 為未中獎。正式活動前請自行設定並按「套用並保存」。

## 抽獎規則

抽獎核心與轉盤繪圖分離。使用系統隨機來源、拒絕取樣消除取餘數偏差，再從 `[0,1000000)` 的整數機率區間抽取一次。顯示設定不參與結果選擇。

不預排結果、不保證中獎、不按历史或期望比例補償結果。每次均依當時的有效機率重新独立取樣。庫存會改變後續有效機率：獎品售罄後，其原機率從下一次抽獎起轉為未中獎。

例如 A=10%、B=20%，未中獎=70%；A 售罄後 B 仍為20%，未中獎=80%。顯示售罄時 A 的10%灰色區塊屬於未中獎；隱藏時 B 的面積仍為20%，未中獎面積為80%。

按下開始時即抽取一次並交易保存，接著播放約3.2秒動畫，在對應區塊中心停下，保留結果約1.6秒。這段時間使用該次抽獎前的機率快照，禁止重複抽獎與修改配置。結果展示結束後轉盤回到下一次可抽的機率畫面，文字標示「上次結果」。

因此動畫途中關閉或當機不會重新抽取或退回庫存：結果已保留於歷史。若資料庫交易失敗，不扣庫存、不新增紀錄、不播放成功動畫。

## CSV 與配置

匯入 CSV 為 UTF-8，固定四欄：

```csv
name,probability,limit,color
頭獎,1.0000,1,#ffd166
二獎,9.0000,5,#70c1ff
```

見 `examples/prizes.csv`。可使用雙引號包住含逗號或引號的欄位；名稱不能換行。匯入先驗證與預覽，確認後取代獎品設定，數量從總數開始，歷史保留。

JSON 保存完整配置與當時剩餘數量；匯出不包含設定鎖密碼。載入 JSON 會保留目前輪次及設定鎖，替換其他配置與庫存。JSON 與 CSV 匯入檔案上限2 MiB。

CSV 歷史匯出使用 UTF-8 BOM；可能被試算表視為公式的欄位會加上單引號，避免被當成公式執行。歷史 CSV 用於查閱，不能當作獎品匯入檔。

## 備份、還原與鎖定

備份使用 SQLite `VACUUM INTO`，包含已提交的配置、庫存與歷史，不需要手動複製 WAL。為避免誤覆寫，備份檔名必須尚未存在。

還原前會先在資料目錄產生 `before-restore-*.sqlite`，再唯讀驗證來源備份及資料格式，最後在同一交易中還原。無效備份不改動目前資料。安全備份不自動刪除，可依自己的保留政策清理。

第一次鎖定設定時輸入並確認至少4字元的密碼。解鎖只對目前執行期間有效，重啟會再次鎖定。再次鎖定需輸入原密碼。本版没有介面變更／移除密碼功能；活動前請先備份並妥善保管密碼。

設定鎖用於防止操作失誤；資料庫未加密，不能抵抗具有本機檔案存取權的人修改資料。
